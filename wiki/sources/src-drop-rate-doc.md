# 来源摘要：物品掉率文件修改说明

> 原文：`物品掉率文件修改说明.md`（源工作区根目录）。所有数值计算规则均依据实际文件内容验证。

## 核心结论（3~5 句）

1. 掉率三件套（深渊 / 普通 / 精英）共享段落结构：`[basis of rarity dicision]`（累计阈值差值法）+ `[item drop ref table]`（物品等级映射）+ 普通/精英专属的 `[drop prob]` 与三组乘法倍率；
2. 一切概率以 **1,000,000 为基数**（曾纠正过"‰"误读）；当前实测：深渊困难/非常困难爆率相同（史诗 4%），普通/精英史诗档几乎为 0；
3. `worlddrop.etc` 是独立的按等级块（1~200，`-1` 分隔）世界掉落池，每物品独立判定，与怪物掉率并行生效；
4. 修改 = 阈值挪移 / 倍率调整，红线是文件名原拼写、阈值递增、末档 = 1,000,000、难度码勿动。
