# etc/worlddrop.etc 世界掉落

定义**世界掉落物品池**：独立于怪物掉率表之外，按**地图 / 怪物等级**分段掉落的固定物品清单（药水、材料、卡片、副本基础奖励等）。怪物死亡时，除走怪物掉率表外，还会**独立判定**一次世界掉落池——两套系统并行生效、互不干扰。

## 文件结构

整段被 `[world drop]` … `[/world drop]` 包裹，内部 200 个**等级块**顺序排列（等级 1~200），块间用**单独一行 `-1`** 分隔：

```
[world drop]
    <等级块 1>
    -1
    <等级块 2>
    -1
    ...
    200  0            ← 最后一块
    -1
[/world drop]
```

### 等级块结构

```
<等级>   0              ← 头部：等级号 + 保留位（恒为 0）
<物品ID> <掉率>          ← 物品对（两个一组）
<物品ID> <掉率>
```

| 字段 | 含义 |
|------|------|
| 头部第 1 列 | 等级号（1 递增到 200） |
| 头部第 2 列 | 保留位，**恒为 0，勿改** |
| 物品行第 1 列 | 物品 ID（须在 equipment / stackable 等 LST 中真实存在） |
| 物品行第 2 列 | 掉率，÷1,000,000（见 [[probability-basis]]；`1000` = 0.1% 而非必掉） |

## 关键规律（实测归纳）

1. **每物品独立判定**：各自 roll，互不影响，一只怪可同时掉多个世界物品。
2. **同一物品在不同等级块可有不同掉率**：典型如 `1106/1107/1108` 系列按等级接力激活（1~5 级块 1106 激活 0.1%、6~15 级块换 1107、16 级起换 1108）。
3. **全等级常驻掉落**：`8669`(0.05%)、`7454`(0.015%)、`690000280`(0.05%)、`7248`(0.1%) 几乎每块都有。
4. 大量 `2500xxx`（装扮券）与低等级段 `2600xxx` 掉率为 0。

## 修改要点

- **定位等级块不要按行号**：按 `-1` 分隔符 + 头部 `<等级> 0` 定位（每个 `-1` 后下一行即新块开头）。
- 提高掉率：改物品行第 2 列（如 `500` → `100000` = 0.05% → 10%）。
- 新增物品：在目标块内、`-1` 之前插入 `<物品ID> <掉率>` 一行。
- 禁用：掉率改 0（保留行）或删行。
- 扩展等级上限（新增 201 级块）：在最后一块的 `-1` 后、`[/world drop]` 前按格式追加。
- **红线**：`-1` 不可省略/错位；物品对必须成对（奇数个数字会让后续全部错位）；保持 Tab 分隔；改完 `save_as_pvf`。

## 与怪物掉率表的对照

| 维度 | `itemdropinfo_monster*.etc` | `worlddrop.etc` |
|------|----------------------------|-----------------|
| 触发主体 | 怪物死亡 | 独立于怪物，按等级段全局生效 |
| 控制内容 | 稀有度分布 + 物品等级范围 | 具体物品 ID + 各自掉率 |
| 分段方式 | 地图等级（`[item drop ref table]`） | 等级块（1~200，`-1` 分隔） |

完整修改流程见 [[modify-drop-rate]]；怪物侧结构见 [[itemdropinfo-family]]。
