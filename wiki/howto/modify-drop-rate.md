# 修改怪物 / 世界掉率完整流程

覆盖 `itemdropinfo` 三件套与 `worlddrop.etc` 的修改。结构详解见 [[itemdropinfo-family]]、[[worlddrop-etc]]；概率算法见 [[probability-basis]]。

## 通用步骤

```
1. get_file_content 读原文（etc/itemdropinfo_*.etc 或 etc/worlddrop.etc）
2. 确认目标段落与当前数值（复算爆率，标注基数 1,000,000）
3. 编辑数值（只动数值，保持 [section] / Tab / 缩进结构，文件名不改）
4. import_file 写回 PVF
5. save_as_pvf 重新打包 → 替换游戏 Script.pvf 后生效
```

## 常见需求配方

### ① 提高深渊史诗爆率（4% → 10%）

改 `itemdropinfo_monster_hell.etc` 的 `[basis of rarity dicision]`，本质是**阈值挪移**（从其他档借空间，总和恒为 1,000,000）：

```
原: 400000 700000 900000 960000 1000000 1000001
改: 400000 700000 900000 900000 1000000 1000001   ← 粉阈值让出 60000
→ 粉 0%、史诗 10%（实际应多档均匀分摊，此处仅示意原理）
```

### ② 让普通副本也能爆史诗

改 `itemdropinfo_monseter.etc`，将粉档阈值从 `1000000` 下调留出史诗空间，并同步保证紫 < 粉递增合法：

```
原: 700000 944900 995000 1000000 1000001 1000002
改: 700000 944900 990000 995000  1000000 1000002   ← 留出 50000 = 史诗 5%
```

### ③ 扩大某等级段掉落装备的等级范围

改 `[item drop ref table]`（下限 = 地图等级 − 第2列，上限 = 地图等级 + 第3列）：

```
原: 50  8  3      （42 ~ 53 级）
改: 50  20 20     （30 ~ 70 级）
```

注意"减去的下限"勿超过地图等级（否则下限为负）。

### ④ 整体提升某类怪物掉率

- 直接调基础：改 `[drop prob]` 对应列数值；
- 间接放大：改 `[monster type drop bonusrate]` / `[dungeon difficulty drop bonusrate]` 倍率（最终 = 基础 × 组队 × 难度 × 类型）。

### ⑤ worlddrop 侧操作

- 提率：改物品对第 2 列（`500` → `100000` 即 0.05% → 10%）；
- 新增：目标等级块内、`-1` 前插入 `<物品ID> <掉率>`（ID 必须真实存在）；
- 禁用：率改 0 或删行；分段激活参照 `1106/1107/1108` 的接力写法。

## 红线清单

1. 文件名保持原拼写（`monseter`）；
2. 阈值严格递增，末档 = 1,000,000；
3. 末列难度码（1000001/1000002）勿改；
4. `-1` 分隔符与物品对成对性（worlddrop）；
5. 概率复算并标注基数 1,000,000；
6. 改完必须重新打包 PVF。
