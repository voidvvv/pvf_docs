# 概率基数 1,000,000 约定

所有掉率 / 稀有度判定 / 世界掉落类数值，**以 1,000,000 = 100% 为基数**，实际值 = 数值 ÷ 1,000,000。

| 数值 | 实际含义 |
|------|----------|
| `0` | 不掉落 |
| `1` | 百万分之一（0.0001%） |
| `1000` | **千分之一 = 0.1%（不是必掉！）** |
| `100000` | 10% |
| `1000000` | 100% 必掉 |

## 稀有度判定算法（累计阈值差值法）

适用 `[basis of rarity dicision]` 段（见 [[itemdropinfo-family]]）。游戏在怪物死亡时 roll 一个 `[0, 1000000)` 随机数，按累计阈值划档：

```
某档爆率 = (本档累计阈值 − 上一档累计阈值) ÷ 1000000
```

- 稀有度顺序固定：白 → 蓝 → 紫 → 粉 → 史诗；第一档（白）的上一档阈值视为 0；
- 末档（史诗）上限固定为 1,000,000；
- 每行**最后一个数字**（如 `1000001` / `1000002`）是难度 / 副本引用码，**不参与计算**。

### 计算示例

原始行 `400000 700000 900000 960000 1000000 1000001`：

| 稀有度 | 计算 | 爆率 |
|--------|------|------|
| 白 | 400000 − 0 | 40.0% |
| 蓝 | 700000 − 400000 | 30.0% |
| 紫 | 900000 − 700000 | 20.0% |
| 粉 | 960000 − 900000 | 6.0% |
| 史诗 | 1000000 − 960000 | 4.0% |

### 修改红线

1. 阈值必须**严格递增**（白 < 蓝 < 紫 < 粉 < 史诗上限），否则判定异常；
2. 末档累计阈值必须 = 1,000,000；
3. 改爆率 = 调整阈值间距挪移空间（如史诗 4%→10% 需从其他档借 6%）。

## 适用范围

| 场景 | 概率形式 |
|------|----------|
| `itemdropinfo_monster*.etc` 的 `[basis of rarity dicision]` | 累计阈值差 |
| `itemdropinfo_monseter*.etc` 的 `[drop prob]` | 每列独立 ÷1,000,000（如 `986` = 0.0986%，**不是 ‰**） |
| `worlddrop.etc` 物品对第 2 列 | 每物品独立判定 ÷1,000,000 |
