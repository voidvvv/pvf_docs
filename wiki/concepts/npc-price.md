# NPC 交易价格：[price] 与 [value]

装备与物品（`.equ` / `.stk`）都有与 NPC 交易的价格字段：

| 标签 | 含义 |
|------|------|
| `[price]` | 从 NPC 处**买入**的价格 |
| `[value]` | 卖给 NPC 的价格**基础值**——**实际卖出价 = `[value]` ÷ 5** |

## ⚠️ int32 溢出上限（2026-11-05 第三实测点判别完成）

游戏卖价计算存在**"先乘后除"的 32 位有符号整数中间量**，乘数已经三个实测数据点判别确认为 **×200 后 ÷1000**（"卖价 20%"的千分率实现）：

- **安全上限：`[value]` ≤ 10,737,418（到手价 ≤ 2,147,483 ≈ 214 万）**
- 实证 1：`[value]`=42,500,000 → ×200 = 8,500,000,000 回绕 −89,934,592 → ÷1000 = **−89,934**（实测吻合）
- 实证 2：`[value]`=20,000,000 → ×200 = 4,000,000,000 回绕 −294,967,296 → ÷1000 = **−294,967**（实测吻合；淘汰 ×100 模型）
- 实证 3（判别探针，用户实测 2026-11-05）：**班图族的金币**（3340）`[value]`=2,500,000 → 游戏内卖价 **500,000**（=2.5M÷5，无溢出）→ **确认 ×200、淘汰 ×1000**（×1000 预测 −358,993）
- 参照物品：班图族的金币（3340，`stackable/material/gold_coin.stk`）——`[price]` 500,000、`[value]` 2,500,000，**卖价恰等于买入价**（数值设计自洽），亦是天然的溢出标定物
- ⚠️ 判别史留痕：曾误判 ×100（单数据点多模型同解时凭未验证旁证选错）；×1000 由第三数据点淘汰。**多模型同解时必须用判别性数据再选**。排查全程见 [[pink-price-incident]]。

### 换算示例

- `[value]` = 10000 → 卖给 NPC 只得 **2000**；
- 实测样本 `equipment/character/common/ring/100322605.equ`：`[price]` 120000、`[value]` 96000 → 卖出价 19200（印证两字段并存；÷5 规则本身以下方来源为准）。

### 修改提示

- 想让某装备/物品卖店更值钱：调 `[value]`（记住玩家到手是 ÷5 后的数），而非 `[price]`；
- `[price]` 影响商店回购/购买侧（如 NPC 贩卖列表，参考 [[pvfdoc-library]]【06】NPC-商店）；
- 改完照常 `import_file` + `save_as_pvf`（见 [[pvfutility-mcp]]）。
