# NPC 交易价格：[price] 与 [value]

装备与物品（`.equ` / `.stk`）都有与 NPC 交易的价格字段：

| 标签 | 含义 |
|------|------|
| `[price]` | 从 NPC 处**买入**的价格 |
| `[value]` | 卖给 NPC 的价格**基础值**——**实际卖出价 = `[value]` ÷ 5** |

## ⚠️ int32 溢出上限（2026-11-04 两轮实测修正后确认）

游戏卖价计算存在**"先乘后除"的 32 位有符号整数中间量**。两个实测数据点判别出乘数为 **×200（÷1000）或 ×1000（÷5000）**（本质都是"卖价 20%"的千分率运算；×100 已被第二个数据点淘汰）：

- **全模型安全上限：`[value]` ≤ 2,147,483（到手价 ≤ 429,496 ≈ 42.9 万）**
- 实证 1：`[value]`=42,500,000 → ×200 = 8,500,000,000 回绕 −89,934,592 → ÷1000 = **−89,934**（实测吻合）
- 实证 2：`[value]`=20,000,000 → ×200 = 4,000,000,000 回绕 −294,967,296 → ÷1000 = **−294,967**（实测吻合；此点同时淘汰 ×100 模型——其预测为 +4,000,000）
- 若需更高上限，可用探针区分乘数：设 `[value]`=2,500,000 → 显示 **500,000** 即 ×200（上限可提至 10,737,418）；显示 **−358,993** 即 ×1000（上限确为 2,147,483）
- ⚠️ 曾误判为 ×100（上限 21,474,836）——单数据点下三种乘数模型均吻合，当时凭未经验证的旁证（"原版 7.5M 物品卖价正常"，该数据还出自不可信的导出副本）选错了分支。**多模型同解时必须用判别性实验/数据再选**。排查全程见 [[pink-price-incident]]。

### 换算示例

- `[value]` = 10000 → 卖给 NPC 只得 **2000**；
- 实测样本 `equipment/character/common/ring/100322605.equ`：`[price]` 120000、`[value]` 96000 → 卖出价 19200（印证两字段并存；÷5 规则本身以下方来源为准）。

### 修改提示

- 想让某装备/物品卖店更值钱：调 `[value]`（记住玩家到手是 ÷5 后的数），而非 `[price]`；
- `[price]` 影响商店回购/购买侧（如 NPC 贩卖列表，参考 [[pvfdoc-library]]【06】NPC-商店）；
- 改完照常 `import_file` + `save_as_pvf`（见 [[pvfutility-mcp]]）。
